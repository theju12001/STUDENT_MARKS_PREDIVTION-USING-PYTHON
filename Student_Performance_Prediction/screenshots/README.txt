SCREENSHOTS TO CAPTURE FOR YOUR PROJECT REPORT / SUBMISSION
=============================================================

This folder intentionally does NOT contain pre-made screenshots. Fake or
staged screenshots would not reflect your own working application, so
please capture these yourself after running the project locally
(`streamlit run app.py`). Save each one into this folder using the
suggested file name below.

Capture the following 10 screens:

1. dataset.png
   - The "Data Analysis" page showing the Dataset Preview table.

2. preprocessing.png
   - The "Data Analysis" page with the "View Preprocessing Details"
     expander opened (shows missing values handled, duplicates removed).

3. data_analysis.png
   - The "Data Analysis" page showing the statistical summary table.

4. study_hours_graph.png
   - The Study Hours vs Final Score chart on the Dashboard page.

5. attendance_graph.png
   - The Attendance vs Final Score chart on the Dashboard page.

6. correlation_matrix.png
   - The Correlation Overview chart on the Dashboard page.

7. model_performance.png
   - The "Model Performance" page showing MAE / MSE / RMSE / R² metric
     cards.

8. actual_vs_predicted.png
   - The Actual vs Predicted chart on the Model Performance page.

9. prediction_screen.png
   - The "Prediction" page showing the empty input form before clicking
     Predict.

10. prediction_result.png
    - The "Prediction" page after clicking "Predict Final Score", showing
      the result card with the predicted score and performance category.

Tips:
- Use your browser's full-page screenshot feature for cleaner captures.
- Keep a consistent browser window size across all screenshots for a
  polished, uniform look in your report.
- Insert these images into docs/Project_Report.md (or your Word/PDF
  version of the report) at the marked "Screenshot placeholder" sections.
